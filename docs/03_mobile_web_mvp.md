# Mobile Web MVP

The MVP is a mobile-first web app that demonstrates the intended user flow without real camera or AI functionality.

## User Flow

1. User taps Start Scan.
2. User sees a camera preview placeholder.
3. User progresses through front, left, right, and hairline scan steps.
4. User uploads a hairstyle reference image.
5. User taps Generate.
6. User sees a result placeholder.

## Frontend Scope

- React + Vite app.
- Mobile-friendly layout.
- Clear scan step indicators.
- File input for the style reference.
- Placeholder result surface.

## Backend Scope

- Placeholder API endpoints.
- Stable route names for the future frontend integration.
- Simple JSON responses.
