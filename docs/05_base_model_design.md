# Base Model Design

The personal base model is the reusable representation of the user's face, head shape, and hairline context.

## Intended Inputs

- Guided scan images.
- Face landmarks.
- Hairline segmentation.
- Side profile cues.
- Optional user metadata in later versions.

## Intended Outputs

- Normalized face profile.
- Head shape approximation.
- Hairline boundary.
- Rendering constraints for hairstyle synthesis.

## MVP Status

The current repository only defines placeholder modules. Real model estimation will be added after scan capture and landmark extraction are validated.
