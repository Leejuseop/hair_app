# Scan Pipeline

The scan pipeline will eventually convert guided user captures into structured face and head information.

## Planned Scan Steps

- Front: primary face proportions and symmetry.
- Left: side profile and head depth cues.
- Right: side profile consistency.
- Hairline: forehead and hair boundary reference.

## Future Processing

1. Validate scan quality.
2. Detect face landmarks.
3. Estimate head and face geometry.
4. Extract hairline and skin boundary cues.
5. Store a reusable scan profile.

## MVP Status

The current MVP only displays scan steps and a camera preview placeholder. No real capture is implemented yet.
